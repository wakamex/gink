# signal-client

The Signal client layer of gsignal's core: linking, the receive loop, sending, and the traits its storage implements.

It began as a copy of the `presage` crate from [presage](https://github.com/whisperfish/presage) at commit `b44d0129348fffde7455214bc081859dcf2fd242` (2026-10-10), copyright its contributors and licensed AGPL-3.0-only, and is changed here as gsignal needs. The licence text is `LICENSE` at the repository root.
